# W3Schools How-To Clone

Proyek ini adalah replika dari halaman [W3Schools How To](https://www.w3schools.com/howto/default.asp). Proyek ini dibangun murni untuk tujuan pembelajaran dalam mendesain antarmuka web (UI) dan mengasah kemampuan *front-end development*.

## 🚀 Fitur Utama
*   **Responsive Design:** Tampilan dapat menyesuaikan dengan berbagai ukuran layar (Desktop, Tablet, Mobile).
*   **Sidebar Navigation:** Menu navigasi kategori di sisi kiri yang interaktif.
*   **Grid Layout:** Penataan kartu (*card*) tutorial yang rapi dan mirip dengan tata letak aslinya.
*   **Search Bar UI:** Tampilan bilah pencarian di bagian atas.

## 🛠️ Teknologi yang Digunakan
*   HTML5
*   CSS3 (Flexbox & Grid)
*   Vanilla JavaScript (untuk interaktivitas UI seperti *toggle* menu)
