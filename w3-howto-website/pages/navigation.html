How To - Top Navigation

❮ PreviousNext ❯

Menu navigasi horizontal di bagian atas halaman.

Buat daftar link di dalam div, lalu beri warna, jarak, dan efek hover lewat CSS. Kelas active menandai halaman saat ini.

Example

<!DOCTYPE html>
<style>
body{margin:0;font-family:Arial}
.topnav{background:#333;overflow:hidden}
.topnav a{float:left;color:#f2f2f2;padding:14px 16px;text-decoration:none}
.topnav a:hover{background:#ddd;color:#000}
.topnav a.active{background:#04AA6D;color:#fff}
</style>
<div class="topnav">
  <a class="active" href="#">Home</a>
  <a href="#">News</a>
  <a href="#">Contact</a>
</div>
