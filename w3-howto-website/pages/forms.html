How To - Login Form

❮ PreviousNext ❯

Formulir login sederhana dengan input dan tombol selebar wadah.

Gunakan box-sizing:border-box agar input dengan width:100% tidak melebihi formulir. Atribut placeholder memberi petunjuk isian.

Example

<!DOCTYPE html>
<style>
form{max-width:320px;font-family:Arial}
input{width:100%;padding:12px;margin:6px 0 12px;border:1px solid #ccc;box-sizing:border-box}
button{width:100%;background:#04AA6D;color:#fff;padding:14px;border:0;cursor:pointer}
button:hover{opacity:.8}
</style>
<form onsubmit="return false">
  <label>Username</label>
  <input type="text" placeholder="Enter Username">
  <label>Password</label>
  <input type="password" placeholder="Enter Password">
  <button>Login</button>
</form>
